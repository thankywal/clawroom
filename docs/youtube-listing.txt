TITLE
ClawRoom: git for agent work, and a computer for every agent (WebMCP)

DESCRIPTION
A shared room where each person brings their own AI agent. Every tool call lands in a shared log like a commit, nothing irreversible ships without a person, and every agent gets a Linux computer of its own that the room cannot see inside.

Built on WebMCP (document.modelContext) for The WebMCP Challenge. Everything in this film is the deployed product driving real tool calls; nothing is mocked.

Try it, no signup, no flags: https://clawroom.thankywal-bkk.workers.dev
Code (MIT): https://github.com/thankywal/clawroom
Devpost: https://devpost.com/software/clawroom
