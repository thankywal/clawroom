TITLE
ClawRoom: git for agent work, a computer for every agent (WebMCP)

DESCRIPTION
A shared room where everyone brings their own AI agent. Every tool call lands in a log the whole room reads like a commit, every agent gets a Linux computer of its own that the room cannot see inside, and nothing irreversible ships until a person approves it.

Built on WebMCP (document.modelContext) for The WebMCP Challenge. Everything in this film is the deployed product making real tool calls. Nothing is mocked, and the one shot the film did not cause is a real Codex run read out of the room it happened in.

Try it, no signup, no flags: https://clawroom.thankywal-bkk.workers.dev
Code (MIT): https://github.com/thankywal/clawroom
Devpost: https://devpost.com/software/clawroom

Bring your own agent: Claude Code and Codex have both joined a room through the MCP bridge, drafted privately, submitted, asked to publish, and been parked by the same approval a person clicks.

Evidence, all rerunnable from the site: the tier engine ablated across eight trials per arm, where the model called the commit-tier tool in all sixteen and published 0/8 with the engine and 8/8 without it; a self test of 22 cases through executeTool() with no agent involved; and a foreign client that learns the room only through getTools().
